# Иконка приложения

Знак — тот же символ питания, что и внутри кнопки подключения. Это не совпадение:
иконка в лаунчере и единственный орган управления в продукте должны быть одной
формой, чтобы иконка читалась как «та самая кнопка» ещё до открытия приложения.

Цвета — только семантические токены из
[docs/04-design-system.md](../../docs/04-design-system.md):

| Элемент | Токен | HEX |
|---|---|---|
| Фон | `bg/canvas` | `#0A0B0D` |
| Диск под знаком | `bg/raised` | `#1B1D21` |
| Кромка | `border/default` | `#24272C` |
| Знак | `status/connected` | `#2FD98A` |

Новых цветов здесь нет и быть не должно.

## Что где

```
icon-1024.png  icon-512.png  icon-192.png   витрины сторов, README, сайт
mipmap-*/ic_launcher.png                     обычная иконка Android
mipmap-*/ic_launcher_foreground.png          передний слой адаптивной иконки
ic_launcher_background.png                   задний слой адаптивной иконки
```

Передний слой нарисован внутри безопасной зоны адаптивной иконки (средние ~66 %
холста) — иначе система обрежет знак маской.

## Как пересобрать

```bash
python assets/branding/generate_icons.py
```

Скрипт рисует с восьмикратным супersampling'ом и уменьшает через LANCZOS:
у Pillow нет сглаживания дуг, и без этого кольцо получается ступенчатым.
Правится там же — геометрия знака задана параметрами, а не захардкожена по точкам.
