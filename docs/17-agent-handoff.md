## БЛОКЕРЫ И ИЗВЕСТНЫЕ ПРОБЛЕМЫ

### Подписка панели не отдаёт узлы

**Статус:** Блокер на стороне **панели**, не клиента. На момент передачи:
- Панель возвращает заглушку `vless://…@0.0.0.0:1` с именем «App not supported»
- `/happ`, `/sing-box`, `/clash-meta` отвечают 502 «Origin upstream unavailable»

**Решение:** Не трать время на перебор User-Agent (уже сделан). Проверить с владельцем статус панели.

### Живой туннель — как проверить?

1. Запусти: `python scripts/panel_test_setup.py --setup`
2. Скопируй URL подписки
3. В Commy приложении: импорти подписку → выбери узел → подключись
4. Проверь: статус `checking` → `connected`, IP изменился

Если не сработало — смотри `docs/16-local-testing.md § Известные проблемы`.
