> `Duration(milliseconds: 237)` за пределами `commy_ui`. Всё через токены.

## Характер

Категория выглядит одинаково: сине-чёрный фон, неон, щиты, риторика страха.
Happ — синий, INCY — зелёный, остальные где-то между. Commy идёт против.

**Нейтральный графит.** База угольная, без тёплого и без синего уклона — чистая
нейтраль с едва заметным холодным сдвигом (B ≥ G ≥ R на 2–6 пунктов). Она не спорит
ни с одним статусным цветом и не выглядит перекрашенной, в отличие от
коричнево-чёрных баз, которые читаются как «сепия по ошибке».

**Бренд-цвет — мел, а не ещё один неон.** Основное действие заливается почти белым
на тёмной теме и почти чёрным на светлой. Брендового оттенка, конкурирующего со
статусом, в системе нет. Отсюда следствие, ради которого всё и делалось: **цвет в
интерфейсе означает ровно одно — состояние подключения.**

**Свечение разрешено в одном месте продукта** — кольцо подключения. Везде ещё
иерархия строится подъёмом фона и границей.

Ощущение: спокойный инструмент, а не пульт от бомбы. Ближе к Raycast и Linear,
чем к NordVPN.

### Контраст

Посчитано по WCAG 2.1 **из фактических значений переменных**, а не переписано
руками. Формат: `Dark / Light`, оба на `bg/surface` своей темы. Порог AA — 4.5:1
для текста, 3:1 для крупного текста и границ интерактивных элементов.

| Токен | Контраст | Вердикт |
|---|---|---|
| `text/primary` | **16.46 / 18.28** | AAA |
| `text/secondary` | **9.07 / 7.74** | AAA |
| `text/tertiary` | **5.83 / 4.92** | AA |
| `accent/solid` | **16.46 / 18.28** | AAA |
| `border/strong` | **3.72 / 3.13** | AA для границ (1.4.11) |
| `status/connected` | **9.93 / 5.39** | AA |
| `status/connecting` | **9.09 / 5.87** | AA |
| `status/error` | **6.37 / 7.71** | AA |
| `status/info` | **7.46 / 6.64** | AA |
| `status/idle` | **5.83 / 4.92** | AA |
| `text/disabled` | 3.72 / 2.10 | исключение WCAG 1.4.3 |

`text/disabled` намеренно ниже порога: 1.4.3 выводит неактивные элементы из-под
требования, а «читаемое неактивное» путает пользователя сильнее, чем тусклое.

Правила:
- `text/tertiary` не используется для мелкого читаемого текста — только подписи и
  метаданные от 13px.
- Цветом **никогда** не передаётся единственный смысл. Статус подключения — это
  цвет + иконка + текст. Задержка — цвет + число + столбики.
- Новый цвет попадает в систему только вместе с посчитанной строкой в этой таблице.

## Типографика

**Inter** (SIL OFL 1.1) — интерфейс. **JetBrains Mono** (SIL OFL 1.1) — логи,
JSON-конфиг, IP-адреса, задержка, значения правил маршрутизации.

Обе гарнитуры **вшиваются в приложение**, а не берутся из системы: одинаковый
рендер на пяти платформах важнее пары мегабайт. Тексты лицензий OFL — на экране
«О программе».

## Пространство

Сетка **4 pt**. Разрешённые значения — и никаких других:

```
space/0   0      space/5   20
space/1   4      space/6   24
space/2   8      space/8   32
space/3   12     space/10  40
space/4   16     space/12  48
                 space/16  64
```

Плотность: мобайл `space/4` как базовый отступ экрана, десктоп `space/6`.

## Движение

| Токен | Длительность | Кривая | Где |
|---|---|---|---|
| `motion/instant` | 90 ms | `easeOut` | Нажатие, hover, чип |
| `motion/fast` | 140 ms | `easeOutCubic` | Переключатель, чекбокс, тултип |
| `motion/base` | 220 ms | `easeOutCubic` | Переход экрана, появление sheet |
| `motion/slow` | 340 ms | `easeOutCubic` | Раскрытие панели, сортировка списка |
| `motion/connect` | 620 ms | пружина (0.85 / 0.5) | Смена состояния подключения |

Принципы:
- Анимация **объясняет** изменение, а не украшает. Нет объяснения — нет анимации.
- Ничего дольше 620 ms. Приложение открывают, чтобы нажать одну кнопку.
- **`MediaQuery.disableAnimations` уважается.** При включённом «уменьшении
  движения» пульсация, вращение дуги и перерисовка кольца трафика заменяются
  мгновенной сменой состояния. Это не опция — это доступность.

## Кнопка подключения

Главный элемент продукта и единственное место, где допустимо свечение.

**Внутри кнопки нет текста.** Ни подписи, ни таймера, ни имени узла. Знак питания
понятен без слов, а всё остальное вокруг него — это шум в самом заметном месте
экрана. Состояние читается цветом ободка, свечением и дугой прогресса.

```
      ↑ 25 КБ/с      ⏱ 00:12:47      ↓ 37 КБ/с      ← строка метрик
                 ╭───────────────╮
                 │      ⏻        │                  ← только знак питания
                 ╰───────────────╯
                  🇳🇱 Amsterdam 03  ⌄                ← что выбрано
                     ⟳ Проверить                     ← только когда подключено
```

Геометрия: контейнер 240 dp, внешний ореол Ø208, диск Ø172, знак питания 62 dp,
штрих знака 2.2. Тап-таргет — весь диск, то есть заведомо ≥ 48 dp.

| Состояние | Ободок | Диск | Ореол | Свечение | Знак |
|---|---|---|---|---|---|
| `idle` | `border/default`, 1.5 px | `bg/raised` | `bg/surface` | нет | `text/secondary` |
| `starting` | `border/subtle` + дуга 270° `status/connecting`, вращение 900 ms линейно | `bg/raised` | `bg/surface` | нет | `status/connecting` |
| `checking` | `status/connected`, 1.5 px + дуга-пробник | `status/connected/wash` | `status/connected` @ 6% | нет | `status/connected` @ 60% |
| `connected` | `status/connected`, 2 px | `status/connected/wash` | `status/connected` @ 9% | `Glow/Подключено`, пульс 2.4 s | `status/connected` |
| `stopping` | `status/idle`, 1.5 px | `bg/raised` | `bg/surface` | нет | `text/disabled` |
| `error` | `status/error`, 2 px | `status/error/wash` | `status/error` @ 7% | `Glow/Ошибка` | `status/error` |

**Свечение живёт на отдельном узле-ободке без заливки.** Если повесить его на
полупрозрачный диск, тень пробьёт насквозь и кнопка станет ядовитым пятном вместо
тёмного диска со светящимся краем. Это не мелочь — на этом ломается весь тон экрана.

### Строка метрик

Отдача, длительность сессии и загрузка — одной строкой над кнопкой, в
`Mono/Strong` (JetBrains Mono Medium 13/20). Крупный таймер внутри кнопки убран
намеренно: цифры меняются раз в секунду и в размере 44 dp превращают спокойный
экран в приборную панель. Когда соединения нет, значения показываются нулями в
`text/disabled` — строка не прыгает при подключении.

Под кнопкой — выбранный узел (флаг + имя + шеврон). Кнопка «Проверить» стоит
**по левому краю контента, над списком**, а не по центру под кнопкой: по центру она
висит в пустоте и спорит с главным действием. Появляется она **только** в состояниях
`connected` и `checking` — проверять нечего, пока туннель не поднят.

**`checking` — отдельное состояние не случайно.** Поднятый туннель ещё не значит
работающий интернет. Пользователь должен видеть разницу между «мы подключились» и
«трафик реально ходит», иначе он будет обвинять приложение в чужих проблемах.

## Навигация: нижнего меню нет

Нижняя панель вкладок из макета убрана. Причина не в моде, а в структуре продукта:
**на мобайле у Commy один основной экран.** Подписки, их узлы и вручную добавленные
группы живут прямо под планетой подключения — то есть на том же экране, где
принимается решение «жать или не жать». Вкладка «Серверы» дублировала бы главную,
а «Маршрутизация» и «Диагностика» открываются в среднем реже раза в неделю: держать
под них четверть нижней панели — плохой обмен.

```
Главная            планета + подписки + узлы   (единственный корневой экран)
  ├ ⚙ слева   →   Настройки
  │                 ├ Маршрутизация
  │                 ├ Диагностика
  │                 └ Внешний вид
  └ ＋ справа →   Импорт (bottom sheet)
```

Освободившаяся высота уходит в список — это ровно то место, где пользователь
проводит время. На планшете и десктопе экономить нечего: там возвращается
`NavigationRail` и двухпанельная компоновка, см.
[05-ux-flows.md](05-ux-flows.md#карта-приложения).

`ConnectionRow` (хост, правило, узел, скорость, длительность) ·
`TrafficChart` (спарклайн скорости за 60 с)

**Оболочки**
`AdaptiveScaffold` · `MobileShell` · `TabletShell` · `DesktopShell` ·
`CommySheet` (bottom sheet на мобайле → диалог на десктопе, один API) ·
`CommyAppBar` (шестерёнка слева, плюс справа, не больше двух действий на сторону)

**Флаги — векторные, а не эмодзи.** `CountryFlag` рисуется из полос и фигур:
26×20, радиус 5, кромка из `border/default`. Эмодзи-флаги зависят от системного
шрифта, ломают высоту строки, а на Windows вообще рендерятся двухбуквенным кодом —
то есть ровно тем, от чего мы уходим.

## Иконки

**Lucide** (ISC). Сетка 24, штрих 1.75, скругления на концах. Единственный набор —
смешивать иконки из разных семейств запрещено, это первое, что выдаёт
непроработанный интерфейс.

Размеры: 16 (в строках текста), 20 (в кнопках и списках), 22 (навигация),
32 (пустые состояния).

В Figma заведены 35 иконок, покрывающие все экраны 1.0, и 10 векторных флагов.
Иконки при реализации берутся из пакета `lucide_icons` — макетные копии не являются
источником истины. Флаги рисуются нашим кодом по данным из макета.

## Токены в коде

Токены — обычный Dart, доступный через тему:

```dart
// packages/commy_ui/lib/src/tokens/colors.dart
@immutable
class CommyColors extends ThemeExtension<CommyColors> {
  final Color bgCanvas, bgSurface, bgRaised, bgOverlay, bgInset, bgScrim;
  final Color borderSubtle, borderDefault, borderStrong;
  final Color textPrimary, textSecondary, textTertiary, textDisabled, textInverse;
  final Color accentSolid, accentHover, accentOnSolid, accentWash;
  final Color statusConnected, statusConnecting, statusError, statusInfo, statusIdle;

  static const dark = CommyColors(
    bgCanvas:  Color(0xFF0C0B0A),
    bgSurface: Color(0xFF171512),
    accentSolid: Color(0xFFF5F2ED),
    statusConnected: Color(0xFF2FD98A),
    // …
  );

  static const light = CommyColors(
    bgCanvas:  Color(0xFFF7F4F0),
    bgSurface: Color(0xFFFFFFFF),
    accentSolid: Color(0xFF171512),
    statusConnected: Color(0xFF0C7A4A),
    // …
  );
}

// Использование
final c = context.colors;      // extension на BuildContext
Container(color: c.bgSurface);
```

Аналогично `CommySpacing`, `CommyRadii`, `CommyTypography`, `CommyMotion`.

**Линт-правило** запрещает литералы `Color(...)`, `Colors.*` и числовые
`EdgeInsets` вне `packages/commy_ui/lib/src/tokens/`.

Имена токенов в Dart — camelCase от имени переменной в Figma: `bg/surface` →
`bgSurface`, `status/connected` → `statusConnected`. Расхождение имён между Figma
и кодом — баг, а не мелочь.

## Проверка перед мержем UI

- [ ] Обе темы выглядят намеренно, а не «светлая получилась сама»;
- [ ] контраст текста проверен по таблице выше;
- [ ] есть golden-тест на dark и light;
- [ ] тап-таргеты ≥ 48 dp;
- [ ] экран не разваливается при системном шрифте 200%;
- [ ] `MediaQuery.disableAnimations` уважается;
- [ ] есть все четыре состояния: загрузка, пусто, ошибка, успех — см.
      [05-ux-flows.md](05-ux-flows.md#обязательные-состояния-каждого-экрана);
- [ ] иконки только Lucide;
- [ ] строки в `slang`, `ru` и `en` заполнены.
