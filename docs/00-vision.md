# 00 · Видение продукта

## Одно предложение

Commy — быстрый, красивый и полностью прозрачный клиент, который подключает
пользователя к **его собственной** сетевой инфраструктуре на любом устройстве.

## Проблема

У человека есть свой сервер (или подписка от знакомого админа / self-hosted панели
вроде Remnawave или Marzban). Чтобы им пользоваться, нужен клиент. Сегодня выбор
такой:

| Клиент | Больно |
|---|---|
| v2rayNG, NekoBox | Только Android, UI образца 2019 года |
| sing-box (SFA/SFI/SFM) | Отличное ядро, но UI — форма для заполнения JSON |
| Hiddify | Все платформы, но интерфейс перегружен, много «магии» под капотом |
| Happ, INCY | Отличный UX — но **закрытый исходный код** |

Ключевая дыра: **нет клиента, у которого одновременно хороший UX, все пять
платформ и открытый код.** Для инструмента, через который идёт весь твой трафик,
закрытый исходник — это не мелочь. Это ровно та ниша, куда заходит Commy.

## Для кого

**Основная аудитория.** Технически грамотный пользователь, у которого есть свой
сервер или подписка. Он умеет вставить ссылку, но не хочет читать документацию
sing-box, чтобы включить split tunneling.

**Вторичная.** Системный администратор, который раздаёт доступ семье и коллегам.
Ему важно, чтобы клиент ставился без объяснений и не звонил домой.

**Третичная.** Разработчик, которому нужно быстро гонять трафик через свой хост
для отладки или доступа к инфраструктуре.

**Мы НЕ целимся** в человека, который хочет нажать одну кнопку и получить
бесплатный VPN. У него нет сервера, а мы серверов не даём.

## Принципы

1. **Свой сервер или ничего.** Никаких встроенных конфигов, каталогов «бесплатных
   серверов» и партнёрских интеграций. Приложение — пустое до первого импорта.
2. **Тишина в сети.** Ноль исходящих запросов, которых пользователь не запросил.
   Ни аналитики, ни crash-репортов, ни «проверки лицензии», ни автообновления.
   Ровно три опциональных исключения, все по действию пользователя, все
   перечислены на одном экране настроек — список
   [закрытый](09-security-privacy.md#тишина-в-сети--правило-r1-и-его-исключения).
3. **Прозрачность важнее удобства.** Каждый сгенерированный конфиг можно открыть
   и прочитать. Каждое «умное» решение приложения объяснимо в UI.
4. **Одинаковое поведение на всех платформах.** Правило маршрутизации, написанное
   на телефоне, работает так же на ноутбуке. Различия — только там, где их
   диктует ОС, и они названы явно.
5. **Красота не опциональна.** Клиент такого класса открывают по десять раз в день.
   Он обязан быть приятным, а не «функциональным».
6. **Мобильный опыт — первичный.** Десктоп не должен быть «мобильным приложением,
   растянутым на 1920px» — но приоритет полировки у телефона.

## Что входит в продукт

**Ядро (M1–M3, обязательно для 1.0)**
- Импорт: ссылки протоколов, подписки, QR, файл конфига, буфер обмена.
- Подключение/отключение, живая статистика скорости и трафика, время сессии.
- Список узлов с замером задержки, группы, автовыбор лучшего.
- Режимы маршрутизации: Global / Rules / Direct, наборы правил geoip/geosite.
- Раздельное туннелирование по приложениям (Android, Windows, Linux).
- Настройки DNS, kill switch, автозапуск, автоподключение.
- Логи ядра и список активных соединений.
- Тёмная и светлая темы, русский и английский языки.

- Блокировщик рекламы через DNS (выключен по умолчанию, источник списков
  настраивается — исключение E-3 в [09-security-privacy.md](09-security-privacy.md)).

**Расширение (после 1.0)**
- Android TV и tvOS.
- Экспорт/импорт настроек, синхронизация через файл (без облака).
- Редактор конфига для экспертов с валидацией.
- Виджеты и шорткаты.
- Больше языков: fa, zh, tr, ar.

**Релиз 1.0 = Android + iOS.** Десктопы выходят как 1.1 (Windows) и 1.2
(macOS, Linux) — см. [07-roadmap.md](07-roadmap.md).

## Явные non-goals

| Не делаем | Почему |
|---|---|
| Свои серверы, продажу трафика, партнёрки | Меняет и юридический, и этический профиль проекта |
| Аккаунты, облачную синхронизацию, бэкенд | Нечему утекать, если ничего не собираем |
| Рекламу, платные функции, «pro»-версию | Опенсорс без подвоха |
| Телеметрию по умолчанию | См. принцип 2 |
| Собственную панель управления сервером | Это отдельный продукт, не клиент |
| Обфускацию клиента ради обхода детектирования сторов | Ведёт к бану и ломает доверие |

## Как меряем успех

Успех — не установки. Успех:

- **Время до первого подключения** для нового пользователя < 60 секунд от
  открытия приложения до зелёного статуса.
- **Стабильность туннеля**: переживает переключение Wi-Fi↔мобильная сеть, сон
  устройства и смену сети без ручного переподключения.
- **Расход батареи** в простое с активным туннелем сопоставим с системным VPN.
- **Воспроизводимая сборка** Android: любой может собрать APK и получить тот же
  хеш, что в релизе. Это то, что оправдывает слово «открытый».
