# 07 · Роадмап

**1.0 = Android + iOS.** Десктопы выходят следом как 1.1 и 1.2.
Порядок обоснован в [ADR-0004](adr/0004-mobile-first-order.md).

> **Где мы на 2026-08-05.** M0 закрыт. M1 написан целиком и **не принят**: все
> четыре пункта приёмки требуют живого туннеля, а он ни разу не поднимался с
> настоящим сервером — подписка владельца отдаёт заглушку вместо узлов. M2 и M3
> сделаны примерно наполовину, и незакрытое отмечено ниже жирным.
>
> Выпущено: `v0.1.0-alpha.2`, APK по трём ABI плюс universal, подписан debug-ключом.
>
> **Следующему агенту:** очередь работ с приоритетами, объёмом и точными файлами —
> [15-handoff.md](15-handoff.md#очередь-работ-по-убыванию-пользы). Начинать оттуда,
> а не отсюда: этот документ говорит «что», а тот — «в каком порядке и где».

```
M0 ─► M1 ─► M2 ─► M3 ─► M4 ─┬─► 1.0   Android + iOS
                            │
                            └─► M5 ─► 1.1   + Windows
                                 └─► M6, M7 ─► 1.2   + macOS, Linux
```

Оценки — в неделях работы, а не календаря. Они условны и нужны для сравнения
этапов между собой, а не для обещаний.

- [x] Опенсорс-обвязка: `LICENSE`, `README`, `CONTRIBUTING`, `SECURITY`, `.gitignore`
- [x] Монорепо: `melos.yaml`, пять пакетов, `apps/commy` под 5 платформ
- [x] Строгий линт (`very_good_analysis`) + правило запрета цветовых литералов
- [x] CI: `analyze` + `test` на каждый PR
- [x] Дизайн-направление «Графит и сигнал»: токены, компоненты, 9 экранов в обеих
      темах — [Figma](https://www.figma.com/design/J416grbo7gykd06gN8cJ8Q)
- [x] **Утверждение направления владельцем**
- [x] `commy_ui`: токены и темы

**Закрыт.** `melos bootstrap && melos run analyze && melos run test` зелёные на
чистом клоне: 657 тестов проходят, 99 golden пропускаются вне Linux. Приложение

## M1 · Android MVP — первый настоящий трафик

**Оценка:** 4–6 недель. Самый важный этап: здесь проверяется вся архитектура.

- [x] `commy_domain`: сущности, `Result`, `CommyFailure`
- [x] `commy_config`: парсеры всех схем (включая Reality) + генератор конфига
- [x] `core/`: обёртка sing-box, `mobile/` под gomobile, сборка AAR в CI под 3 ABI
- [x] Android: `VpnService`, `PlatformInterface` (15 методов из 15, сверено `javap`),
      foreground-уведомление, `BootReceiver`, плитка в шторке, `DozeMonitor`
- [x] `AndroidCoreClient`: `MethodChannel` + `EventChannel`, контракт сверяется
      машинно (`scripts/check_wire_contract.py`)
- [x] Экраны: главный, импорт, настройки, маршрутизация, внешний вид, «О программе»,
      диагностика (логи, соединения, конфиг, статистика)
- [x] Deep links: 6 схем плюс файлы и шаринг текста

**Критерий приёмки не выполнен ни по одному пункту** — все четыре требуют живого
туннеля, а он ни разу не поднимался с настоящим сервером:

1. [ ] APK на реальном устройстве гонит трафик через собственный сервер;
2. [ ] туннель **переживает переключение Wi-Fi ↔ мобильная сеть** без ручного
   переподключения — не пересоздавая TUN, а уведомляя ядро через `PlatformInterface`;
3. [ ] туннель переживает сон устройства и Doze;
4. [ ] отказ пользователя в системном диалоге VPN даёт понятную ошибку, а не тишину.

> **Чем заблокировано.** Подписка владельца отдаёт заглушку «App not supported»
> вместо серверов — одинаково для 19 испробованных клиентских User-Agent, а
> форматные пути панели отвечают 502. Разбор ответа при этом проверен на живой
> Remnawave и сходится целиком. Нужен рабочий источник узлов, и всё; см.
> [15-handoff.md](15-handoff.md).

## M2 · Подписки и узлы

**Оценка:** 3–4 недели.

- [x] Парсеры всех схем ссылок + подписок (список, base64, Clash YAML, sing-box JSON)
- [x] Импорт: URL, QR, файл, deep links, вставка из буфера
- [x] `subscription-userinfo`: квота, срок, `profile-title`, интервал обновления —
      проверено на живой панели Remnawave
- [ ] **Автообновление подписок** — карточка пишет «авто 1 ч», планировщика нет
- [ ] **Список узлов**: «замерить все» без прогресса и отмены, поиска и сортировки нет
- [x] Смена узла без разрыва туннеля (`select` внутри работающего ядра)
- [x] Состояние `checking` — выводится в Dart после `connected`
- [x] Secure storage для кредов; шифрование файла БД отложено осознанно —
      [ADR-0007](adr/0007-database-encryption.md)
- [x] Локализация ru/en через `slang`
- [ ] Функции: A2–A15, B6, B10, B11, C1–C5, C10, F3, F4, G2, G8, G9, G11

**Готово, когда:** подписка на 100+ узлов из реальной панели импортируется, часть
битых записей уходит в `import_failures` с причинами, замер всех узлов не вешает UI,
профили переживают перезапуск приложения.

## M3 · Маршрутизация, DNS, блокировщик

**Оценка:** 4–5 недель.

- [x] Режимы Глобально / Правила / Прямо
- [ ] **Наборы правил geoip и geosite** — загрузки нет. Правила, которые их
      называют, выбрасываются при сборке конфига; теперь хотя бы с предупреждением
      в логе и баннером, а не молча
- [x] Свои правила с приоритетом и сортировкой перетаскиванием
- [ ] **Раздельное туннелирование по приложениям** — домен, генерация конфига и
      Kotlin готовы сквозь весь стек, **нет только экрана выбора** и метода
      «перечислить установленные пакеты»
- [ ] **DNS** — `DnsSettings` смоделирован и генерируется целиком, экрана нет
- [ ] Блокировщик рекламы через DNS — переключатель есть, списков нет (нужен E-2)
- [x] Kill switch — отдан системе: строка ведёт в «Постоянный VPN» Android,
      потому что процесс, которого убили, ничего не блокирует
- [x] Автоподключение при запуске
- [x] Автозапуск при загрузке — переключатель включает `BootReceiver` через
      `setStartOnBoot`; сам receiver умеет только уведомление (правило R2)
- [x] Активные соединения, график скорости
- [ ] **Статистика по дням** — `DriftTrafficHistoryStore` написан и не подключён
- [ ] Функции: A16, A17, B7–B9, B12, C6–C9, C11, D1–D9, E1–E7, F5, F6, F9, F10, G4, H2

**Готово, когда:** пройден полный [чек-лист утечек](09-security-privacy.md#чек-лист-утечек),
в том числе при обрыве туннеля и в режиме always-on VPN.

## M4 · iOS — главный риск проекта

**Оценка:** 5–8 недель, из них значительная часть вне нашего контроля.

- [ ] Apple Developer Program, entitlement `networkextension`, App Group
- [ ] `gomobile bind` → `Libbox.xcframework`
- [ ] Target `CommyTunnel`: `NEPacketTunnelProvider`
- [ ] IPC через unix-сокет в контейнере App Group
- [ ] **Профилирование памяти: удержаться в 50 MiB** на реальных устройствах
- [ ] On-demand rules — автоподключение по SSID и типу сети
- [ ] Подготовка ревью: объяснение «мы не VPN-сервис», ссылка на исходники
- [ ] Функции: H3

**Готово, когда:** расширение не убивается jetsam за сутки непрерывной работы,
включая тяжёлые наборы правил и активную нагрузку.

> **Escape hatch.** Если к концу M3 нет доступа к Apple Developer Program, либо
> если ревью затягивается более чем на месяц, **1.0 выпускается как Android-only**,
> а iOS становится 1.1. Проект не стоит из-за чужой очереди модерации.

## M5 · Windows → 1.1

**Оценка:** 3–4 недели.

Служба с правами администратора + Wintun, локальный TCP с токеном, Clash API как
транспорт, трей, автозапуск, портативный режим. Инсталлятор MSIX и portable-zip,
манифест WinGet. Функции G5–G7, H4, H5, H7, D6 для Windows.

**Готово, когда:** установка не требует объяснений, а закрытие окна не рвёт туннель.

---

## M6 · macOS → 1.2

**Оценка:** 2–3 недели (переиспользует код Apple из M4).

`SMAppService` + привилегированный хелпер + `utun`, подпись и нотаризация, DMG,
пункт в menu bar. App Store как второй канал позже. Функция H6.

---

## M7 · Linux → 1.2

**Оценка:** 3–4 недели. Недооценивать не стоит: DNS на Linux — отдельная работа.

Хелпер с `CAP_NET_ADMIN`, авторизация через polkit, три стратегии управления DNS
(systemd-resolved, NetworkManager, голый `resolv.conf` с watchdog). Пакеты:
AppImage, Flatpak, `.deb`, `.rpm`. Работоспособность без трея. Функция H8.

## M8 · После 1.2

Приоритет определяется обратной связью, а не этим списком: Android TV и tvOS,
редактор конфига с валидацией, профили по расписанию, языки fa/zh/tr/ar, виджеты,
Shortcuts, перенос настроек между устройствами через файл.

## Что может сломать план

| Риск | Вероятность | Что делаем |
|---|---|---|
| iOS-ревью затягивается или отказ | Средняя | Escape hatch в M4: 1.0 без iOS |
| Лимит 50 MiB не держится с большими правилами | Средняя | gVisor-стек, загрузка правил с диска, урезание наборов на iOS |
| Ломающее изменение в `libbox` | Средняя | Пин версии, бамп отдельным PR (R8) |
| Linux DNS ломает систему пользователю | Средняя | Watchdog в хелпере, обязательное восстановление |
| Google Play снимает VPN-приложение | Низкая | F-Droid и прямой APK как основные каналы, Play как дополнительный |
| Проект не догоняет по времени одиночку | **Высокая** | Этапы нарезаны так, чтобы каждый давал работающий артефакт. Резать надо объём, а не качество этапа |
