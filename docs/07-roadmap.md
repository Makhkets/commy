# 07 · Роадмап

**1.0 = Android + iOS.** Десктопы выходят следом как 1.1 и 1.2.
Порядок обоснован в [ADR-0004](adr/0004-mobile-first-order.md).

```
M0 ─► M1 ─► M2 ─► M3 ─► M4 ─┬─► 1.0   Android + iOS
                            │
                            └─► M5 ─► 1.1   + Windows
                                 └─► M6, M7 ─► 1.2   + macOS, Linux
```

Оценки — в неделях работы, а не календаря. Они условны и нужны для сравнения
этапов между собой, а не для обещаний.

---

## M0 · Фундамент

**Цель:** проект можно собрать, и есть на чём писать код.

- [x] Спецификация в `docs/`, `CLAUDE.md`, ADR 0001–0005
- [ ] Опенсорс-обвязка: `LICENSE`, `README`, `CONTRIBUTING`, `SECURITY`, `.gitignore`
- [ ] Монорепо: `melos.yaml`, `.fvmrc`, пять пакетов, `apps/commy` под 5 платформ
- [ ] Строгий линт (`very_good_analysis`) + правило запрета цветовых литералов
- [ ] CI: `analyze` + `test` на каждый PR
- [x] Дизайн-направление «Графит и сигнал»: токены, компоненты, 9 экранов в обеих
      темах — [Figma](https://www.figma.com/design/J416grbo7gykd06gN8cJ8Q)
- [ ] **Утверждение направления владельцем** — блокирует `commy_ui`
- [ ] `commy_ui`: токены и темы — **после утверждения**

**Готово, когда:** `melos bootstrap && melos run analyze && melos run test` зелёные
на чистом клоне, приложение запускается пустым экраном на Android и на десктопе
разработчика.

> 📐 Дизайн-система ждёт одного решения: владелец утверждает направление
> «Графит и сигнал» (`docs/04-design-system.md`), после чего `commy_ui` строится
> по готовым макетам. Каркас монорепо, домен, парсеры и Go-ядро от этого не зависят
> и делаются параллельно.

## M1 · Android MVP — первый настоящий трафик

**Оценка:** 4–6 недель. Самый важный этап: здесь проверяется вся архитектура.

- [ ] `commy_domain`: сущности, `Result`, `CommyFailure`
- [ ] `commy_config`: парсер `vless://` (включая Reality) + генератор конфига
- [ ] `core/`: обёртка sing-box, `mobile/` под gomobile, сборка AAR в CI
- [ ] `native/android`: `VpnService`, `PlatformInterface`, foreground-уведомление
- [ ] `AndroidCoreClient`: `MethodChannel` + `EventChannel`
- [ ] Экраны: главный, логи, просмотр сгенерированного конфига, минимум настроек
- [ ] Функции: A1, A6, B1–B5, F1, F2, F7, F8, G1, G3

**Готово, когда** (это критерий приёмки, а не пожелание):

1. APK на реальном устройстве гонит трафик через собственный сервер;
2. туннель **переживает переключение Wi-Fi ↔ мобильная сеть** без ручного
   переподключения — не пересоздавая TUN, а уведомляя ядро через `PlatformInterface`;
3. туннель переживает сон устройства и Doze;
4. отказ пользователя в системном диалоге VPN даёт понятную ошибку, а не тишину.

## M2 · Подписки и узлы

**Оценка:** 3–4 недели.

- [ ] Парсеры всех схем ссылок + подписок (список, base64, Clash YAML, sing-box JSON)
- [ ] Импорт: URL, QR, файл, deep links, вставка из буфера
- [ ] `subscription-userinfo`: квота, срок, `profile-title`, интервал обновления
- [ ] Автообновление подписок
- [ ] Список узлов: группы, задержка, «замерить все», сортировка, поиск
- [ ] Смена узла без разрыва туннеля
- [ ] Состояние `checking` — проверка, что трафик реально идёт
- [ ] Шифрование БД (SQLCipher) + secure storage
- [ ] Локализация ru/en через `slang`
- [ ] Функции: A2–A15, B6, B10, B11, C1–C5, C10, F3, F4, G2, G8, G9, G11

**Готово, когда:** подписка на 100+ узлов из реальной панели импортируется, часть
битых записей уходит в `import_failures` с причинами, замер всех узлов не вешает UI,
профили переживают перезапуск приложения.

## M3 · Маршрутизация, DNS, блокировщик

**Оценка:** 4–5 недель.

- [ ] Режимы Глобально / Правила / Прямо
- [ ] Наборы правил geoip и geosite — загрузка по явному действию
- [ ] Свои правила с приоритетом и сортировкой перетаскиванием
- [ ] Раздельное туннелирование по приложениям (Android)
- [ ] DNS: раздельные резолверы, DoH/DoT/DoQ, FakeIP, защита от утечек
- [ ] Блокировщик рекламы через DNS
- [ ] Kill switch, автоподключение, автозапуск
- [ ] Активные соединения, график скорости, статистика по дням
- [ ] Функции: A16, A17, B7–B9, B12, C6–C9, C11, D1–D9, E1–E7, F5, F6, F9, F10, G4, H2

**Готово, когда:** пройден полный [чек-лист утечек](09-security-privacy.md#чек-лист-утечек),
в том числе при обрыве туннеля и в режиме always-on VPN.

## M4 · iOS — главный риск проекта

**Оценка:** 5–8 недель, из них значительная часть вне нашего контроля.

- [ ] Apple Developer Program, entitlement `networkextension`, App Group
- [ ] `gomobile bind` → `Libbox.xcframework`
- [ ] Target `CommyTunnel`: `NEPacketTunnelProvider`
- [ ] IPC через unix-сокет в контейнере App Group
- [ ] **Профилирование памяти: удержаться в 50 MiB** на реальных устройствах
- [ ] On-demand rules — автоподключение по SSID и типу сети
- [ ] Подготовка ревью: объяснение «мы не VPN-сервис», ссылка на исходники
- [ ] Функции: H3

**Готово, когда:** расширение не убивается jetsam за сутки непрерывной работы,
включая тяжёлые наборы правил и активную нагрузку.

> **Escape hatch.** Если к концу M3 нет доступа к Apple Developer Program, либо
> если ревью затягивается более чем на месяц, **1.0 выпускается как Android-only**,
> а iOS становится 1.1. Проект не стоит из-за чужой очереди модерации.

## M5 · Windows → 1.1

**Оценка:** 3–4 недели.

Служба с правами администратора + Wintun, локальный TCP с токеном, Clash API как
транспорт, трей, автозапуск, портативный режим. Инсталлятор MSIX и portable-zip,
манифест WinGet. Функции G5–G7, H4, H5, H7, D6 для Windows.

**Готово, когда:** установка не требует объяснений, а закрытие окна не рвёт туннель.

---

## M6 · macOS → 1.2

**Оценка:** 2–3 недели (переиспользует код Apple из M4).

`SMAppService` + привилегированный хелпер + `utun`, подпись и нотаризация, DMG,
пункт в menu bar. App Store как второй канал позже. Функция H6.

---

## M7 · Linux → 1.2

**Оценка:** 3–4 недели. Недооценивать не стоит: DNS на Linux — отдельная работа.

Хелпер с `CAP_NET_ADMIN`, авторизация через polkit, три стратегии управления DNS
(systemd-resolved, NetworkManager, голый `resolv.conf` с watchdog). Пакеты:
AppImage, Flatpak, `.deb`, `.rpm`. Работоспособность без трея. Функция H8.

---

## M8 · После 1.2

Приоритет определяется обратной связью, а не этим списком: Android TV и tvOS,
редактор конфига с валидацией, профили по расписанию, языки fa/zh/tr/ar, виджеты,
Shortcuts, перенос настроек между устройствами через файл.

## Что может сломать план

| Риск | Вероятность | Что делаем |
|---|---|---|
| iOS-ревью затягивается или отказ | Средняя | Escape hatch в M4: 1.0 без iOS |
| Лимит 50 MiB не держится с большими правилами | Средняя | gVisor-стек, загрузка правил с диска, урезание наборов на iOS |
| Ломающее изменение в `libbox` | Средняя | Пин версии, бамп отдельным PR (R8) |
| Linux DNS ломает систему пользователю | Средняя | Watchdog в хелпере, обязательное восстановление |
| Google Play снимает VPN-приложение | Низкая | F-Droid и прямой APK как основные каналы, Play как дополнительный |
| Проект не догоняет по времени одиночку | **Высокая** | Этапы нарезаны так, чтобы каждый давал работающий артефакт. Резать надо объём, а не качество этапа |
