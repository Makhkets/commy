## Чего здесь нет

- **Светлая тема.** Страница `04 · Экраны · Светлая` — производная от тёмной,
  собирается переключением режима переменной. Отдельно не выгружалась: значения
  светлых токенов есть в таблице дизайн-системы, а композиция та же.
- **Планшет и десктоп.** Нарисован только мобайл 390×844.
- **Вкладки диагностики** «Соединения», «Конфиг», «Статистика» — в макете только
  заголовки.

Как обновить: см. [12-figma-handoff.md](../12-figma-handoff.md) — там ID всех
кадров и подключение к Figma MCP.
