# ADR-0021 · Сланец по умолчанию и компактная главная

Статус: принято владельцем 2026-11-02 после сравнения визуальных макетов.

## Решение

Добавить `AppThemeMode.slate`, не переименовывая сохранённые `dark`, `light`
и `system`. Новая установка и документ без поля темы получают slate;
явный выбор существующего пользователя сохраняется. Чёрная тема использует
прежнюю палитру dark, светлая — light; все три используют одни компоненты.

Главная показывает трафик, кнопку, выбранный сервер, статус и проверку.
Подписка и серверы — единая поверхность с внешними полями. Выбор отмечен
нейтральной заливкой и семантикой selected, без галочки и боковой полосы.
Четыре полоски задержки и число дублируют цвет. Протоколы остаются цветными
словами; транспорт голубой, VLESS лаймовый, TLS/Reality мятные.
Поиск и сортировка раскрываются из шапки; активный поиск остаётся видимым.
Авто находится внутри подписки только когда она представляет всю библиотеку;
при нескольких источниках глобальный выбор остаётся отдельным.

## Последствия

Сетевой код, подписки, секреты и маршрутизация не меняются. Кнопка продолжает
отменять запуск и не принимает повторных команд при остановке. Диагностика
ошибки разрешения сохраняет путь устройства. Данные квоты и объявления
панели остаются доступны; безлимит не изображается процентом заполнения.
Тесты контраста и golden охватывают три темы. README получает снимки
настоящих Flutter-виджетов с тестовыми, не пользовательскими данными.
