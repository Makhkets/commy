### Светлая тема — производная, руками не трогать

`04 · Экраны · Светлая` целиком собирается из тёмной. После любой правки тёмной
пересобери:

```js
const light = await figma.getNodeByIdAsync('2:5');
await figma.setCurrentPageAsync(light);
// шрифты: Inter Regular/Medium/Semi Bold, JetBrains Mono Regular/Medium
for (const c of [...light.children]) c.remove();
const semCol = (await figma.variables.getLocalVariableCollectionsAsync())
  .find(c => c.name === 'Semantic');
const LIGHT = semCol.modes.find(m => m.name === 'Light').modeId;
const clone = (await figma.getNodeByIdAsync('67:931')).clone();
light.appendChild(clone);
clone.name = 'Экраны · Светлая тема';
clone.x = 0; clone.y = 0;
clone.setExplicitVariableModeForCollection(semCol, LIGHT);
clone.fills = [{ type: 'SOLID', color: { r: 0xC9/255, g: 0xCE/255, b: 0xD4/255 } }];
```

Заливка доски — намеренно не токен: это фон презентации, а не интерфейса.

### Как собирается группа подписки

Одна карточка на подписку: `radius/md`, фон `bg/surface`, `clipsContent = true`.

```
Карточка группы (bg/surface, radius/md, clip)
├─ Шапка подписки (88:74) — фон bg/group-header
└─ Строка узла ×N (73:115) — разделитель = нижняя обводка border/subtle,
                              у последней строки её нет
```

Ступень фона между шапкой и узлами — единственное, что связывает подписку с её
серверами. Отдельными карточками они читались как несвязанные блоки.

## 6. Грабли, на которых уже потоптались

Всё это ловилось в этом файле — не наступай второй раз.

| Симптом | Причина | Как правильно |
|---|---|---|
| Высота фрейма застряла на 10 (или на любом значении из `resize`) | `resize()` сбрасывает `primaryAxisSizingMode` и `counterAxisSizingMode` в `FIXED` | Сначала `resize()`, **потом** режимы сайзинга |
| Строка раздулась до 100 px | Пустой auto-layout фрейм держит дефолтные 100×100 | Не используй пустые фреймы как распорки — ставь `layoutSizingHorizontal='FILL'` на текст и `textAlignHorizontal='RIGHT'` |
| `FILL can only be set on children of auto-layout frames` | `layoutSizing*` выставлен до `appendChild` | Сначала `appendChild`, потом `FILL` |
| `Cannot move node. New parent is an instance` | Пытаешься вставить узел внутрь инстанса | Вложенные инстансы меняются через `nested.swapComponent(comp)` |
| Поиск инстанса по имени варианта не находит ничего | Инстанс называется именем **набора**, не варианта | `await inst.getMainComponentAsync()` и сверяй `mc.parent.name` |
| `findOne` вернул не то | Совпало имя текстового слоя | Ищи по `type` + имени или сразу по id |
| Абзац не переносится, обрезан в одну строку | `textAutoResize` слетел в `NONE` | `t.resize(w, 20)` **потом** `t.textAutoResize = 'HEIGHT'` |
| Кнопка светится изнутри ядовитым пятном | Свечение — это drop-shadow позади узла, а заливка полупрозрачная (`*/wash` = 14%), и тень бьёт насквозь | Свечение вешается на отдельный узел-ободок **без заливки** |
| Вложенные фреймы стали белыми | `figma.createAutoLayout()` создаёт фрейм с белой заливкой по умолчанию | Сразу `f.fills = []` |
| Файл не переименовывается | `figma.root.name` возвращает служебное `Document` | Только руками в интерфейсе Figma |

Плюс правила из скилла, которые здесь особенно важны: **одна смена
`setCurrentPageAsync` на вызов** (для многостраничной работы — параллельные вызовы),
шрифты грузятся в каждом скрипте заново, `use_figma` атомарен — упавший скрипт
не оставляет мусора.
