# iOS: сборка и готовность к публикации

2026-11-05. Это статус реализации, **не подтверждение готовности App Store**.

Добавлен проект `apps/commy/ios/Runner.xcworkspace`: приложение и расширение
CommyTunnel, iOS 16+. Общий платформенный контракт Dart управляет VPN через
NETunnelProviderManager. Расширение запускает закреплённый libbox с лимитом
памяти и двумя семействами IP. Пароли и конфиг находятся в общем Keychain;
наборы правил копируются в App Group, поскольку расширение не видит каталог
основного приложения. Логи проходят через существующий редактор Dart.

Сборка на Mac с полным Xcode:

```sh
scripts/build_core.sh apple
melos bootstrap
melos run gen --no-select
scripts/build_ios.sh
```

В CI есть `.github/workflows/ios.yml`: сборка ядра, приложения и расширения
без подписи. Она не подтверждает прохождение трафика или возможность установки.
Для подписанной сборки выбрать свою команду Apple в обоих targets, зарегистрировать
`dev.commy.app`, `dev.commy.app.CommyTunnel`, `group.dev.commy.app`, включить
Network Extensions, App Groups и Keychain Sharing в профилях обоих targets.
При смене идентификаторов согласовать `COMMY_APP_GROUP`, bundle IDs и общий
Keychain во всех plist и entitlements. Скрипт `build_ios.sh` берёт числовую версию без `alpha` и номер сборки из
`pubspec.yaml`; расширение наследует их из Flutter xcconfig.

## Открытые условия приёмки

- Полная сборка Xcode и подписанная установка на iPhone/iPad.
- Матрица протоколов, IPv6-only/NAT64, DNS, Wi-Fi ↔ cellular, сон, перезапуск,
  авария расширения, восстановление UI после закрытия приложения.
- Замер peak RSS расширения под нагрузкой: бюджет 50 MiB. Наличие
  `with_low_memory` и `LibboxSetMemoryLimit` само по себе не доказывает бюджет.
- Чек-лист утечек docs/09 необходимо пройти заново на iOS. Android-результаты
  не являются результатами iOS. Always-on kill switch здесь не обещается.
- Проверить TCP/GET, корректность всех причин ошибок в логах, подписку с HWID,
  недоступную панель, истёкший TLS, зеркала, импорт QR/файла/deep link,
  экспорт на iPad и доступность интерфейса. ICMP пока отвечает unavailable.
- Добавить доступную внутри приложения политику приватности и предварительное
  раскрытие обработки данных. Необходимый по CLAUDE.md навык design-protocol
  в этой среде не найден; этот UI пока не реализован.
- Подготовить публичный URL политики, данные поддержки, screenshots,
  App Privacy и review notes с рабочим тестовым сервером владельца.
  Не коммитить пароль тестового сервера. Подписка — конфигурация, покупок нет.
- Проверить финальные privacy manifests всех бинарных компонентов, декларации
  шифрования и права на распространение зависимостей с GPL в выбранном канале.

[Apple App Review Guidelines, 5.4](https://developer.apple.com/app-store/review/guidelines/#vpn-apps)
требуют для VPN-приложений организационную учётную запись разработчика и раскрытие
обработки данных до использования. Наименование «прокси-клиент» не гарантирует
исключения. Решение об одобрении принимает Apple.

На локальном Mac установлен только Command Line Tools: полного Xcode и iPhone
для этих испытаний нет. Поэтому готовность к публикации не заявляется.
